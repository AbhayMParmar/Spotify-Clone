🎵 Spotify Clone
A responsive music streaming web application inspired by Spotify. This project is built using HTML, CSS, and JavaScript. It allows users to browse curated playlists and control playback of sample songs. The UI mimics Spotify's layout and design to deliver a familiar user experience.


## 📁 Project Structure
.
├── home.html            # Main landing page displaying music categories
├── Aboutus.html         # Basic About Us page with navigation
├── p1.html              # Hindi playlist - Hot Hits
├── p2.html              # Yo Yo Honey Singh playlist
├── style.css            # Custom styling and layout definitions
├── script.js            # Audio player logic for p1.html
├── Img/                 # Logo, background, and gif assets
├── Covers2/             # Cover images for songs in P1 and P2
├── songs2/              # Audio files for playlists

## 🚀 Features

- 🎧 Responsive music streaming UI
- 🏷️ Playlist display with song covers, names, and timestamps
- ▶️ Custom JavaScript audio player with:
  - Play/Pause toggle
  - Next/Previous controls
  - Seekbar (progress bar)
- 📱 Mobile-friendly design
- 🎨 Clean and dark-themed interface
- 🧭 Simple navigation bar across pages

---

## 🛠️ Technologies Used

- **HTML5** – Structure and markup
- **CSS3** – Styling, layout, animations
- **JavaScript** – Dynamic behavior and audio controls
- **Font Awesome** – Icons for player controls


## 📂 Pages Overview

- `home.html`: Entry point displaying curated playlists
- `p1.html`: A playlist titled *Best of Hindi – Hot Hits*
- `p2.html`: A dedicated *Yo Yo Honey Singh* playlist with audio control script inline
- `Aboutus.html`: Placeholder About Us page
